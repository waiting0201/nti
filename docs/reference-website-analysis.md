## 二、共通模式（5 家一致的做法）

1. **白底＋深藏青/炭灰文字**是此產業的「企業標準色」，靠**大量留白**而非鮮豔色彩建立高級感。
2. **全幅 hero**（影片或大圖輪播）+ 標語 + CTA 是統一開場。
3. **卡片式模組**統一比例與間距，建立節奏感。
4. **sticky 頂部導覽 + 多層下拉**，多語切換放右上角。
5. 偏好**真實攝影／產品照**敘事，少用裝飾性動畫——傳達穩定、可信賴。

## 三、對 NTI 官網的具體建議（對照規劃書）

### 1. 配色 — 在產業標準上做出 NTI 差異
其他家都是「白＋藏青」的安全牌。NTI 核心是 **"The Courage to Print Green 永續 All In!"**：
- 主色維持白底＋深色文字（專業可信）
- **點綴色用「綠」**（呼應永續主軸），手法類似 LSC 用橘色點綴，但換成代表環保的綠，立即與競品區隔，又強化品牌精神。

### 2. Hero 區 — 學 Amcor 的永續主打
首頁 Banner/Videos 與 COURAGE 區塊，建議採 **全幅影片 + 永續標語 + CTA**（Get a Quote／Contact），首屏即講清「Print Green」精神。

### 3. Advantages 綠色優勢 — 學 CCL 的數據統計區塊
「碳效率、環保材料、ESG」適合做成 CCL 那種**大數字＋圖示**統計區塊（碳排減量 %、回收材料佔比），把抽象永續變成可信數據。

### 4. Certifications & Partnerships — 學 LSC 的 Logo 矩陣
FSC、ISO 認證與合作夥伴，適合用 LSC 那種**整齊 logo tile 網格**呈現，乾淨且有公信力。

### 5. 多語與導覽 — 學 Toppan
中／英雙語需求，Toppan 的「右上角語系切換＋多層下拉選單」是成熟範本；Printing Solution 子選單可照此設計。
